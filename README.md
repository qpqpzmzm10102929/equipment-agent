# 🎒 借物小管家

基于 DeepSeek、MCP 和 Streamlit 的校园活动器材借用智能体。

用户可以用自然语言描述需求，由智能体查询器材、检查空闲时段，并在用户确认后创建或取消预约。

## 1. 需求与使用场景

校园采访、社团活动和课堂展示经常需要借用麦克风、三脚架、投影仪等器材。

传统的表格登记方式要求用户自行查找器材、核对时间。本项目希望让用户通过对话完成这些操作，例如：

> 我要用手机拍双人采访，应该借哪些器材？

> 帮我查一下双人无线麦克风明天下午两点到四点能不能借。

> 帮我取消刚才创建的预约。

项目当前使用 6 件示例器材和一个固定的演示用户，不连接学校真实的器材管理系统。

## 2. 功能介绍

| 功能 | 说明 |
|---|---|
| 自然语言对话 | 理解用户需求，并用中文回答 |
| 器材查询 | 根据关键词查询器材名称、用途和兼容性 |
| 空闲查询 | 查询指定器材在某个时间段是否已有有效预约 |
| 创建预约 | 支持一张预约单包含多件器材 |
| 预约查询 | 查看当前演示用户的预约记录 |
| 取消预约 | 取消整张预约单，释放对应时段并保留记录 |
| 多轮对话 | 在当前页面会话中理解“刚才那张预约”等上下文 |
| 操作确认 | 创建和取消预约前显示确认卡片 |
| 工具记录 | 展示实际调用的工具、参数和返回结果 |
| 网页界面 | 提供智能助手、器材库和我的预约三个页面标签 |

## 3. 为什么它是 Agent

本项目由大模型根据用户需求选择工具，并根据工具的实际返回结果继续处理任务。

以预约器材为例：

1. 用户用自然语言提出借用需求。
2. 模型判断需要哪类器材，并调用查询工具。
3. 模型根据器材说明给出建议，必要时追问时间等信息。
4. 模型调用空闲查询工具。
5. 用户明确要求预约后，模型生成预约申请。
6. 网页展示器材、时间及确认按钮。
7. 用户点击确认，程序通过 MCP 调用预约工具。
8. 工具检查冲突并写入 SQLite，网页展示真实执行结果。

模型负责理解需求和选择工具；业务代码负责数据校验、冲突检查和数据库操作。

## 4. 技术方案

| 技术 | 用途 |
|---|---|
| Python 3.12 | 项目开发语言；本项目已在 Python 3.12.14 下运行 |
| DeepSeek API | 自然语言理解、回复生成和工具选择 |
| OpenAI Python SDK | 通过兼容接口调用 DeepSeek |
| MCP Python SDK | 工具发现与调用 |
| SQLite | 保存器材和预约数据 |
| Streamlit | 网页界面 |
| python-dotenv | 从本地配置文件读取 API Key |

整体调用关系：

```text
用户输入自然语言
        ↓
Streamlit 网页
        ↓
Agent 对话逻辑 ↔ DeepSeek API
        ↓
MCP 客户端
        ↓ stdio
本地 MCP 服务
        ↓
器材与预约业务逻辑
        ↓
SQLite 数据库
```

网页中的创建和取消请求先保存为待确认申请。
用户点击确认按钮后，才通过 MCP 执行对应操作。

## 5. MCP 工具

| 工具名称 | 功能 |
|---|---|
| search_equipment | 查询器材 |
| check_availability | 检查指定时间段的空闲情况 |
| create_reservation | 创建预约 |
| list_reservations | 查询当前演示用户的预约 |
| cancel_reservation | 取消预约 |

查询工具可以直接执行；网页中的创建和取消操作需要用户点击确认按钮。

## 6. 业务规则

- 所有业务时间统一按北京时间解释。
- 工具接收的时间格式为 `YYYY-MM-DD HH:MM`。
- 结束时间必须晚于开始时间。
- 同一件器材的有效预约不能时间重叠。
- 两个预约可以首尾相接，例如 14:00–16:00 与 16:00–18:00。
- 多件器材一起预约时，任意一件存在冲突，整张预约单都不会创建。
- 创建预约时会在数据库事务中重新检查冲突。
- 取消预约保留历史记录，但不再占用器材时段。
- 放弃待确认申请不会创建或取消预约。
- `active` 表示有效预约，`cancelled` 表示已取消。

时间冲突判断条件：

```text
已有预约开始时间 < 新预约结束时间
并且
已有预约结束时间 > 新预约开始时间
```

## 8. 运行方法

以下以 Windows PowerShell 为例。

### 8.1 准备环境

安装 Python 3.12，下载项目代码，然后在项目根目录打开终端。

创建虚拟环境：

```powershell
py -3.12 -m venv .venv
```

安装依赖：

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

以下命令直接使用虚拟环境中的 Python，不需要手动激活环境。

### 8.2 配置 DeepSeek API Key

首次配置时，将 `.env.example` 复制为 `.env`：

```powershell
Copy-Item .env.example .env
```

如果已经有 `.env`，请保留原文件，不要重复覆盖。

编辑 `.env`，填写自己的密钥：

```dotenv
DEEPSEEK_API_KEY=你的真实密钥
```

当前代码调用的模型为 `deepseek-flash`，接口地址为：

```text
https://api.deepseek.com
```

模型调用需要网络连接及可用的 API 账户额度。
真实密钥仅保存在本地，不要提交到公共仓库或放入截图。

### 8.3 启动网页

```powershell
.\.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1
```

打开终端显示的本地地址，默认是：

```text
http://127.0.0.1:8501
```

器材和预约表会自动初始化。
Agent 在需要时自动启动本地 MCP 子进程，不需要另外手动运行 MCP 服务。

停止网页服务：在运行服务的终端按 `Ctrl+C`。

### 8.4 可选：命令行运行

```powershell
.\.venv\Scripts\python.exe agent.py
```

### 8.5 可选：连通性检查

检查 MCP 工具发现和查询：

```powershell
.\.venv\Scripts\python.exe test_mcp.py
```

检查 DeepSeek API 连接：

```powershell
.\.venv\Scripts\python.exe test_deepseek.py
```

DeepSeek 连通性检查会发起实际模型请求。

## 9. 使用示例

### 查询器材

输入：

> 帮我查一下有哪些麦克风，并说明它们适合什么场景。

助手调用器材查询工具，返回双人无线麦克风、有线领夹麦克风及其用途。

### 连续追问

继续输入：

> 双人采访那款明天下午两点到四点能借吗？

助手结合前文识别器材，转换时间后查询空闲情况。
演示时应核对页面中的具体日期。

### 创建预约

输入：

> 帮我预约刚才那款麦克风，就用刚才查询的时间。

核对待确认卡片中的器材与时间，点击“确认执行”。

成功后，页面显示预约编号，“我的预约”中出现有效记录。
如果不需要预约，可以点击“放弃”。

### 取消预约

输入：

> 帮我取消刚才创建的那张预约。

助手查询记录并生成取消申请。
核对预约编号后点击“确认执行”，该记录变为“已取消”。

## 11. 当前范围与后续改进

当前版本用于课程演示：

- 固定使用 `demo-user`，尚未实现登录和多用户权限。
- 对话历史保存在当前页面会话中，刷新或断开会话可能丢失。
- 器材和预约数据保存在本地 SQLite 数据库中。
- 尚未实现语音交互、直接修改预约、领取和归还管理。
- 当前没有禁止预约过去的时间，演示时请自行选择合适日期。

后续可以扩展用户登录、管理员器材维护、到期提醒和语音交互。
